<h1 align="center">Buildora</h1>
<p align="center"><b>محرر فيديو احترافي يعمل بالكامل على جهازك — بدون إنترنت وبدون حساب</b></p>

<p>
Buildora محرر فيديو بواجهة عربية داكنة مستوحاة من برامج المونتاج الاحترافية. يعمل كتطبيق ويندوز (exe) أو داخل المتصفح، وتبقى مشاريعك وملفاتك على جهازك مع حفظ تلقائي محلي.
</p>

<h2>المميزات</h2>

<h3>🎞 المونتاج</h3>
<ul>
  <li>طبقات بلا حد أقصى، ويمكنك اختيار نوع كل طبقة: فيديو أو صور أو صوت أو نص.</li>
  <li>نقل المقاطع وقصها وتقسيمها ونسخها وضمّها وحذفها مع سدّ الفراغ، مع تراجع وعلامات (Markers).</li>
  <li>استيراد الملفات بالسحب والإفلات، وتكبير الـ Timeline وملاءمته للمشروع.</li>
  <li>قص أي جزء من الفيديو من الجهات الأربع بمقابض تسحبها داخل المعاينة.</li>
</ul>

<h3>◆ الحركة والانتقالات</h3>
<ul>
  <li>Keyframes للموضع والحجم والتدوير والشفافية، مع لوحة منفصلة للتحكم في سرعة الحركة.</li>
  <li>15 حركة جاهزة: Pop وانزلاق وارتداد واهتزاز ونبض وتأرجح وغيرها.</li>
  <li>انتقالات: Fade وZoom وSlide وBlur وGlitch وWipe وFlash وSpin، وFlip ثلاثي الأبعاد أفقي ورأسي.</li>
</ul>

<h3>🧊 الـ 3D والألوان</h3>
<ul>
  <li>إمالة الفيديو والصور والنصوص في الفضاء بمنظور حقيقي، بالأزرار أو بـ <code>Ctrl</code> + السحب على المعاينة.</li>
  <li>نصوص 3D ذات عمق.</li>
  <li>سطوع وتباين وتشبّع وتدرّج لون، وLooks جاهزة، وفينيت وحبيبات فيلم.</li>
  <li>كروما كي (الشاشة الخضراء)، وطبقة تعديل (Adjustment Layer)، وأوضاع دمج، وظل وتدوير حواف.</li>
</ul>

<h3>🔤 النصوص والصوت</h3>
<ul>
  <li>نصوص بخطوط وألوان وحدود وكتابة تدريجية، وأشكال وثلث سفلي (Lower Third).</li>
  <li>استيراد ترجمة بصيغة SRT.</li>
  <li>مستوى صوت وكتم وFade In وFade Out، وموجة صوتية تظهر على المقاطع.</li>
</ul>

<h3>💾 الحفظ والتصدير</h3>
<ul>
  <li>حفظ تلقائي محلي مع قائمة بالمشاريع الأخيرة.</li>
  <li>أبعاد 16:9 و9:16 و1:1 و4:3.</li>
  <li>تصدير بجودة 480p أو 720p أو 1080p، بصيغة WebM أو MP4، وبمعدل 24 أو 30 أو 60 إطاراً.</li>
  <li>تجميد إطار والتقاط صورة PNG منه.</li>
</ul>

<h2>التشغيل</h2>

<ol>
  <li>فك ضغط مجلد <code>Buildora-Windows</code>.</li>
  <li>افتح <code>Buildora.exe</code> من داخل المجلد. قد يعرض ويندوز تحذير SmartScreen عند أول تشغيل لأن الملف غير موقّع: اختر «مزيد من المعلومات» ثم «تشغيل على أي حال».</li>
  <li>أنشئ مشروعاً جديداً، واستورد ملفاتك أو اسحبها إلى النافذة، وابدأ المونتاج.</li>
</ol>

<h2>التشغيل من الكود المصدري</h2>

<pre>
npm install
npm start          # تشغيل التطبيق
npm run dist       # بناء ملف exe على ويندوز
</pre>

<p>أو افتح <code>index.html</code> مباشرة في Chrome أو Edge.</p>
